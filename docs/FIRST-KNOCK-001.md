# FIRST-KNOCK-001 — One useful thing

**Goal:** a person unfamiliar with the repository constellation can do one concrete thing with CANNON: choose NEED, OFFER, QUESTION, or BUILD; write one sentence; produce a printable field card or an unsent local JSON draft.

This is a human-facing *software fixture*, not a multi-repository crossing, authenticated messaging system, or evidence that help occurred. CANNON's Creative Switchyard already contains genuine source-native media routes, but those are scoped to their pinned original Genesis source, not arbitrary user requests. FIRST-KNOCK deliberately refuses to pretend otherwise.

## Open

Download examples/first-knock-001.html and open it in a browser (file:// works without an internet connection). Nothing to install or connect. Change the fictional sentence, choose a kind, press POKE BACK → MAKE A CARD, then either print the card or save a local draft JSON. The status remains DRAFT_NOT_SENT.

The form's original sample is fictional. Nobody is contacted. Printing or saving occurs only after a visitor presses that button. No account, cookies, tracking, backend, connected Garden, Facebook poke, JAR;VIS, reLATTE, Modal, model inference, provider credentials, or production deployment. No personal information is sent to CANNON.

Run the dependency-free regression tests:

    node --test test/first-knock-page.test.mjs

The tests check a fixed SHA-256 of the exact HTML fixture, syntactic operation of the embedded JavaScript, four present choices, a generated card from a test sentence, manual print/save triggers, and refusal of control characters. The digest is a consistency check, **not** an independently trusted signature. Browser rendering and real human usefulness still need a field test.
