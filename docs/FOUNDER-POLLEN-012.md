## Cross into a sovereign review receiver

The complete Founder Node result, native workbench handoff, exact source witnesses, proposed branch loadout and CANNON 008 read-only inspection report form a canonical-addressed dossier.

Original reLATTE R14 creates a signed opaque-organ crossing carrying the complete dossier, writes file transport, then the destination signs separate RECEIVED and R3_HOLD receipts. A cold replay re-executes only the original pure Founder Node selectors, rereads the original Git source objects, recomputes the dossier, verifies crossing and receipts, checks bundle identity and receiver durable HOLD.

No GHoT ACT ticket is issued and no Toaster Lab or Haunted Toaster software is executed. The Founder Node runtime itself is not started; only its original isolated pure routing functions run.

## Commands

With all five repositories separately checked out to their precise source commits, supply a roots JSON object mapping full repository names to checkout paths:

    node scripts/founder-pollen-012.mjs discover roots.json
    node scripts/founder-pollen-012.mjs run roots.json /tmp/new-founder-pollen-012
    node scripts/founder-pollen-012.mjs verify roots.json /tmp/new-founder-pollen-012

The last two commands require reLATTE dependencies installed in its pinned checkout. No network request happens inside the bridge; separate CI checkout actions fetch the pinned original sources.

## Limits

Pollen ranking is evidence-based relevance, not permission.
Registry claims are not independent proof of every referenced law.
Review catalog source choice is explicit and external to Pollen.
Module source verification is not runtime compatibility verification.
Toaster's downstream admission is separate from its upstream proposal.
A reLATTE receiver HOLD neither admits a branch nor authorizes GHoT work.
