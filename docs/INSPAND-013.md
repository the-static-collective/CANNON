# INSPAND-013 — A field of REAL software contracts

**Stack:** CANNON INSPAND-012 draft PR #83 (the original National Treasure → Iron Lung → CANNON research cycle). **New scope:** a bounded, source-pinned field of 5 actual software repositories with six investigated *candidate* crossings. This is not a compatibility declaration, automatic interface compiler, or authority grant.

## What changed

We are no longer repeatedly asking about a single successful CANNON adapter. We inspect exact original source at fixed commits in:

- **planZ**, `reactor/recursive.mjs`: `static-collective/planz-recursive-reactor/v1/proposal` with status `PROPOSED_UNVERIFIED`, not a rendered performance.
- **PlayDeck**, `packages/core/src/PerformanceReceipt.ts` and `packages/receipts/src/validateReceipt.ts`: typed `PerformanceReceipt`; only full-performance evidence and resolved descendants permit inheritance.
- **The Haunted Toaster**, `src/full-measure/src/render/dogram-trace.cjs`: the explicit `full-measure.video-receipt.v1` required for `dogram.trace-source/v0`, comparison-only, not visual or historical equivalence.
- **lemonPRESS**, `src/vinyl-proof.mjs`: original `lemonpress/vinyl-preflight/v1` draft holds: `HOLD_NOT_ORDERABLE`, no media rights, licenses, physical pressing authorization or album masters.
- **CANNON**, existing source-native `compileTruth()`: known local `SOURCE_PROOF → VISUAL_STUDY` typed `VERIFIED_RECEIPT_PLAN_ID_V1` adapter and operator-selected original planZ source.

Four external source repositories plus CANNON make five verified interface owners. The checkouts are pinned to their *original* owners' Git commits and exact file Git blobs; the adapter vocabulary is extracted from original source, never from a model's answer.

This produces six initial and six follow-up original National Treasure receipts. They are questions, never answers, source-owner approvals, newly invented executable adapters, or human instructions.

## Original Iron Lung: optional speculation, no control

The separate `scripts/multi-repo-iron-lung.mjs` asks the **original source-owning** Iron Lung `triple-transfer` implementation to inspect the first question for each field edge, using the original owner implementation pinned at `307754cfe5c4fb0ca5cae7f50073961a761d3d28`.

- Fixture control: all six questions × nine original 3×3 transfers = **54 deterministic fixture transformations**.
- Actual model: the two unverified PlayDeck→Toaster and Toaster→lemonPRESS questions × nine original Google FLAN-T5 Small transfers = **18 pretrained-model transformations**.

Every input is explicitly marked as using **Iron Lung's original synthetic braid fixture**, not actual ancestry of these external repositories. All outputs are `PROPOSAL_UNVERIFIED`, no admitted facts, inferred rights, selected action, code execution or source modification. A model producing a convincing identifier is not proof that an adapter exists.

Model runs are separately built and cold replayed; the CI workflow also runs original source tests for planZ, PlayDeck, Toaster, lemonPRESS and National Treasure, and independently checks each Git source and packet. Deliberately altered original owner source and forged research outputs are refused.
