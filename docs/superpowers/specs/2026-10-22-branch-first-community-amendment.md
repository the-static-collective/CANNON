## Proper "still holds breath" method, revised

An **evidence ladder**, applied per repo AND per useful branch rather than pretending each repo has one current state:

1. **Address**: recorded repo, ref and exact head commit. Every branch is a candidate; it gets no operational title by mere name.
2. **Relation**: compare branch with default and likely ancestors/child branches. Record ahead/behind, divergence, duplicate content, dependency on stacked PR, and ancestry relationships. Parallel branches must not be ordered by name alone.
3. **Content**: classify observed source code, fixtures, tests, docs, assets, build scripts, demos. Read exact files, not just README. No "current" claim unless source and date support it.
4. **Review state**: list linked open/closed/merged PRs, reviews, merge-base and release tags. Closed-unmerged ≠ worthless; merged ≠ owner adoption; existing branch ≠ unmerged.
5. **Verification**: evidence of successful tests or reproducible run under pinned dependencies, not CI badge inference. Label stale/unknown separately.
6. **Human/local judgment**: owner declares one of `ACTIVE_REFERENCE`, `REUSE_CANDIDATE`, `HISTORICAL_WITNESS`, `CONFLICTING_EXPERIMENT`, `HOLD`, `DECLINED`, with justification. The survey can recommend, never assign.
7. **One real field crossing**: only one source-native owner-approved adapter may leave the sandbox after tests, privacy review, and an independently observed community act. Cross-repo compatibility is a new proof, never inferred from shared project vocabulary.

Every branch retains an independently attributable identity. Branch head SHAs are exact observations, not cryptographic signatures of truth or evidence of deployment.
