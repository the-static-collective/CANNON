# INSPAND-009 — Facts, ideas and relationships **inside** the words

**Original runtime:** Iron Lung COMPASS-003, draft stacked on COMPASS-002 PR #10, pinned by CANNON `registry/content-compass-lock-v1.json`. This experiment implements the operator's specific change: remove the role-tag lines `FACT sourced`, `IDEA speculative`, `RELATION typed`, and equally remove role headings such as `SOURCE ...` or `ADAPTER ...`. The prompt must **mean** something rather than declaring a category.

## Actual source, not placeholder entities

CANNON directly reuses its original `extractActualContract()` function. It reads and verifies the existing `registry/reflex-compositions-v1.json` and `registry/reflex-library-v1.json`. The exact real source states:

- `SOURCE_PROOF` wrapper produces `cannon.reflex-memory/v1`.
- `VISUAL_STUDY` consumes `planz.generated-plan/v1`.
- The previously verified connecting adapter is `VERIFIED_RECEIPT_PLAN_ID_V1` using source field `reusableRecipe.planId`.
- Direct port types do **not** match; the verified adapter is required.
- Only explicit local synthetic tests are authorized. The model never grants rights, runs scripts, reassigns interfaces, or publishes.

Every actual model prompt contains only two–three words per line, and the fact, possible idea and relationship appear as **content**, e.g.:


The `You` address appears only in treatment arms that deliberately request second-person direction; the other arms say `Identify the`. Every card remains source-bound, with exact source hashes, a parent-step chain and original FLAN-T5 Small revision.

## Eight fair call-count arms with real controlled scenarios

The original Iron Lung source-owning runtime generates nine serial, recursive model replies in each of these eight conditions:

1. Actual known adapter present, neutral short dyads.
2. Actual known adapter present, second-person short dyads.
3. Actual known adapter present, neutral more tightly focused dyads.
4. Actual known adapter present, second-person more tightly focused dyads.
5–8. Repeat with a **synthetic scenario where the original known adapter is deliberately unavailable**.

The second scenario does not claim CANNON is actually broken or lacking an adapter. It is a declared counterfactual created by withholding the genuine adapter during a synthetic evaluation. The source type pair remains the same verified pair. A successful compatibility decision is `READY_FOR_SYNTHETIC_TEST` only when the known adapter is available; the direct-only mismatch is `HOLD_TYPE_MISMATCH`. Neither outcome is authorization to execute. The question sequence also tests original output/input port identification, direct type-match and receipt field.

**Total: 72 actual model calls in the pretrained FLAN job**, and 72 separate deterministic fixture calls in its distinct control job. Each arm has an equal nine-request *call* budget, but prompt token counts vary. Every generated response is retained unverified. CANNON re-runs original Iron Lung inference during cold replay and independently validates the owner source commits, model provenance, equality of the actual source task, exact answer match, nonempty 2–3-word line constraints, absence of role headers, response repetitions and prompt echo.

### What this experiment can establish

The method can measure whether 2–3-word **meaning-bearing** statements help FLAN-T5 answer *specific existing-source compatibility questions*, and whether using `you` in context changes exact answers. It cannot establish novelty, invention of an adapter, broad logical competence, improved creativity, human efficiency, real-world impact, actual independent human consent, or safe autonomous execution.

No role headers are sent in this experiment. No software generated by the model is executed. No capabilities are added to the Reflex Library. Even a correct source answer is retrieval, not invention.
