# GENESIS-BOOT-001 — CANNON invokes original experimental code at its own Git history

**State:** open-PR executable experiment, stacked on CANNON CULTURE FORGE #37, itself stacked on the unmerged PRESENT USE branch. Not selected operational canon and not merged into CANNON main.

**Thesis:** one portable Suitcase makes the *first* physical model of a cooperative city visible by composing one fictional Living House; a second simulated house receives a different set of component observations. Open PRs remain independent Git histories. CANNON checks out **exact commit objects** and executes only reviewed, bounded original functions: `MAIN != CANON`, `TESTED != SELECTED`, `SELECTION != EXECUTION` and `CI != FIELD WITNESS`.

## A and B: two live software proofs, not two human witnesses

**A — First boot:** original JAR;VIS consumes the original source-pinned WebZ HARMONY manifest and selects a human-reviewed Founder mission. Original STATIC OS #91 HOUSE-SEED code generates a deterministic *unknown-inventory* Living House plan plus a self-contained printable construction guide. No house, linux OS or sensor is installed.

**B — Second hypothetical household:** original STATIC OS code is invoked again with a different fictional, explicitly unverified survey: a roof/window and solar module are described as `PRESENT_UNVERIFIED`, but no solar controller exists. The resulting house plan must be distinct and retains its actual missing-part hold. **A/B are not independent people, not a field trial, not two signed organizational keys, not a real local power reading.**

**Also executed during both:** original GHoT Commons Machine #129 processes a synthetic physical-relational event scenario with genuine HOLD and REFUSE decisions. Original WebZ HARMONY-004 and GrO MATTERCRAFT-001 operate through already-developed CANNON CULTURE FORGE #37 to generate an actual local six-panel HTML comic and public-safe Markdown field card, with a separately verifiable receipt. Real material stock, deeds, PENNY and energy use remain zero/unknown.

All original source uses are **byte-checked against their original Git commit/tree/blob objects** and locally configured Git origin. This proves the exact code was executed, not GitHub account authentication, a qualified real-world steward or a physically deployed outcome.

## Run the same experiment independently

From a directory containing those exact git checkouts as siblings (`cannon`, `webz`, `gro`, `staticos`, `ghot`, `jarvis`):

```sh
node cannon/scripts/genesis-boot.mjs build \
  --staticos staticos --webz webz --gro gro --ghot ghot --jarvis jarvis \
  --out genesis-output \
  --question "Can one Suitcase help an ordinary house become cooperative infrastructure?"

node cannon/scripts/genesis-boot.mjs verify \
  --staticos staticos --webz webz --gro gro --ghot ghot --jarvis jarvis \
  --out genesis-output
```

The workflow `.github/workflows/genesis-boot-001.yml` checks out the exact source refs, runs the relevant independent test suites, executes the cross-source program, cold-verifies all generated bytes, refuses a deliberately modified file, and publishes the actual complete `genesis-output/` as a GitHub Actions downloadable artifact.

**Open `genesis-output/first-boot.html`** to see the script-free, entirely offline beginning: *HELLO, WORLD. What shall we build together?* It links to `house-A.html`, `house-B.html`, `house-A.json`, `house-B.json`, the produced `comic.html`, `field-card.md`, the original JAR;VIS candidate, and the original GHoT physical-scenario proposal. `boot-receipt.json` contains source SHA/object witnesses and output digests. The only files changed are create-only files in the operator-chosen output directory (and temporary files in a cleaned-up OS temp directory); all donor roots are read-only.

## Proof boundary and integration gaps

**Earned only after GitHub Actions succeeds:**
- original independent code actually executed from several experiment branches;
- A and B distinctly computed HOUSE-SEED work cards;
- original source Git bytes and output bytes can be cold-replayed;
- GHoT's refusal/holds survived composition;
- a usable offline HTML first-boot exhibit and a printable cultural object exist.

**Not earned:** an interactive/bootable Linux OS, physical house, real power measurements, real spoken conversation or local speech capture, separate real operators, signed cross-party reLATTE exchange, GrO/PENNY inventory, independently verified Deeds, native Full Measure integration, real construction permission, actual social impact, a submitted MIT application or selection of any code as owner canon.

**Field B still requires physical participants.** We must not relabel a fictional A/B inventory test as independent witness proof. The next real-world milestones are an authorized ordinary low-voltage physical bench, two human stewards with genuinely separate custody, an independently confirmed measurable result, and an opt-in receiving organization. `GENESIS-BOOT-001` is the executable integration harness to prepare that work.

**More source donors:** Other experimental branches remain freely executable **when their source owner supplies an inspectable, pinned, bounded adapter**. We deliberately don't treat an arbitrary open pull request as authorized to run shell commands. That preserves both CANNON's purpose and practical safety.
