# CANNON

**Canon is selected evidence, not the default Git branch.**

This repository is the entry point for **CANON FIELD**: a signed, owner-selected atlas of independently surviving Git histories. `main` remains a discoverable porch and bootstrap, not the exclusive authority for a project or an experimental outcome.

Principles:

- **MAIN ≠ CANON** — Git's default branch is one address, not the universal verdict.
- **MERGED ≠ ADMITTED** — merging alone does not select a revision.
- **TESTED ≠ SELECTED** — evidence can support selection, but cannot grant ownership.
- **CANON ≠ EXCLUSIVE** — distinct scopes can select different exact commits.
- **SUPERSEDED ≠ DELETED** — historical decisions remain independently verifiable.
- **SIGNATURE ≠ TRUTH** — a signature binds a claim to a known signer; it does not independently certify source, testing, rights or deployment safety.
- **SELECTION ≠ EXECUTION** — even operational canon is no automatic permission to run software or physical machinery.

An executable CANON FIELD 001 candidate will be developed on a branch and reviewed by pull request. This bootstrap does not itself admit any code, alter any other repository, or create an owner trust anchor. 

The owner decides which signed histories and versions are canon for each scope.
