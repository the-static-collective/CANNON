# CANNON-095 — Original PNG Source → GRAFT Visual Programs → Independent Evidence

The entrypoint for **MOTIF image-in visual imagination** is a genuinely decoded **RGB PNG file**, not fabricated text pretending to be a picture. The reader itself is original, exact source-pinned MOTIF-006, while the **new raster transformation program** is actually synthesized by original, exact source-pinned GRAFT-030.

This CANNON experiment:
1. Reads real start and goal PNG binary bytes; checks SHA256 to match the issued MOTIF image-difference gap. Invokes the original MOTIF-006 PNG reader against those same actual bytes, confirming the evidence is independently replayable.
2. Inspects the original unmerged GRAFT-030 Git commit and exact source tree bytes; runs its original finite-grammar three-program synthesis.
3. Recompiles GRAFT's chosen `move` program byte-for-byte, validates rejected `copy` and `recolor` alternatives, and runs the executable on **eight separate synthetic raster examples**, five permitted and three refusals not shown to GRAFT for source selection.
4. Independently compares its program to an elementary **classical exact pixel shift using the identical image and action information**; both attain 8/8 on the small test set. There is **no measured algorithmic superiority**.
5. Saves the actual generated JS source and its content SHA, PNG hashes, source provenance, independent test results, and negative authority fields as `cannon.visual-program-review.v0`, state `HOLD_VISUAL_SOURCE_NOT_ADMITTED`.

This is **not real-world scene understanding**: each image is 3..16 pixels wide/tall and restricted to white empty cells, one red 2×2 object, and stationary blue obstacles; arbitrary photographs are explicitly rejected. The image-input interpreter uses bounded Python standard library PNG decoding. There are no model calls, internet photo uploads, live image acquisition, external actions, identities, or automatic admission to MOTIF.

The receipt may be used as candidate evidence by MOTIF-006's image-to-imagination planner. The reviewer does not authorize deployment or access to private images. Source SHA alone proves content identity, not signature or ownership approval.
