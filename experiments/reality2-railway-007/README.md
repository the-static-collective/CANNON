# LITTLE YES EXPRESS — REALITY.2 × Living Railway × GROOVETOWN 007

**One computer, a table, and 2–6 players. The game is on the players' side.** This is a **new independent CANNON adapter**, not the live Reality 2.0 website or an authorized rail, firewood or token system. Offline-first, no login, network call, service worker or external API. Open `index.html` directly in a modern browser, or print its cards.

## A fifteen-minute version

1. Sit together; use the default four fictional seats (or choose 2–6). Read out the three missions.
2. In sequence, each seat picks one action; everyone may discuss suggestions, and no one owns the commons.
3. Gather from finite fictional production tiles. Craft `WOOD + ORE → 2 RAIL` or `WOOD → 2 FIREWOOD` tokens.
4. A proposed route requires a table's fictional **LITTLE YES** action before it can be built; building consumes actual counted game rail tokens. Clicking a map line does the appropriate next step.
5. Built routes carry cargo. Deliver 2 firewood from Millford and 2 food from Cedar Junction to Lantern Town; also connect Millford to Lantern by rail. Complete all three goals by round nine.
6. The dispatcher suggests a concrete next action, based on the current graph, required costs and inventory. It is a **deterministic heuristic**, not AI or a command. A round roll and scripted event give the game a voice.
7. Every craft, built route and shipment creates a fictional, locally portable card, with material and route provenance. Export JSON, or print the party kit. A SHA-256 digest may be added on export where browser WebCrypto is available. No NFT is minted on any real blockchain.
8. After play, take a **blank** NEED/OFFER/BUILD/LITTLE YES/ARRIVAL field card to identify a real question, never claiming the game's tokens or approvals are real.

## What is borrowed as inspiration and what is actually executed

- The historical Reality 2.0 **Little Yes** rule and Living Railway/Ticket to Arrive sketch inform optional party-game encounters, without importing commercial game code, branding or graphics. The railway is a deliberately original map and recipe system, not licensed Catan/Ticket-to-Ride/Pandemic content.
- GrO Mattercraft PR #32 documented `42 WOOD claimed` versus `39 observed` **disputed** witness count. The game preserves the distinction: its audit action awards one fictional **idea token**, NEVER spendable wood. The game does NOT run GrO-native witness code or turn the count into real stock.
- GHoT Warm Thread PR #33 considered fallen tree / cutter / hauler / warmth need with independent acts. The **wood→firewood** in-game recipe is a toy material transformation with no instructions for cutting, hauling, combustion, heating, property rights or fire safety.
- The old NFT/token idea appears as **exportable story/provenance cards** — no actual crypto issuance, asset title, financial claim, off-chain settlement, rights or transfer of physical inventory.
- `bridge.mjs` imports and **executes CANNON GROOVETOWN-006's original `compare()`** for one read-only Two-Ticket side quest (1→4 conditional modeled goals). The party engine does not pretend its game rules are the original CANNON 006 solver, and the side quest does not grant anything to the physical world. Other source owners (reLATTE, planZ, Reality 2.0 live) are **named lineage**, not executed or edited.

## Run tests

```sh
node --test experiments/reality2-railway-007/game.test.mjs experiments/reality2-railway-007/bridge.test.mjs
node experiments/reality2-railway-007/bridge.mjs
```

`index.html` is a fully self-contained offline bundle generated by replacing the `/* __ENGINE_INSERT__ */` marker in `shell.html` with the engine code after removing its module exports. The Node tests execute the original `game.mjs` source. For publishing a changed engine, regenerate the HTML from the exact source in CI before relying on the version on a site. No deployment was performed.

## Fail-closed / evidence discipline

`PLAY YES != VOLUNTARY FIELD CONSENT`. `PLAY RECEIPT != REAL DEED`. `GAME WOOD != LOCAL STOCK`. `DIGEST != TRUTH`. `DIGITAL CARD != SPENDABLE NFT`. An apparently successful fictional game must not auto-authorize roads, rail structures, property use, energy/firewood work, community outreach, fundraising or payments. There is no permissionless minting, no real-world asset ownership, no credentials and no personal data intake. The group can print, leave the game, and choose what work — if any — they actually want to propose.

All code and the current story are proposed as a separate CANNON draft. The operational Reality 2.0 Waseca branch and its moderation workflow are left unchanged.
