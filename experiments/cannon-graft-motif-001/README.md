## Experiment

GRAFT generates numerous executable numeric projection candidates, rejects decoys, and selects `observed.reachable_actions`. A fresh untouched final set of four cases checks generalization in that bounded grammar.

A simplistic train-only first-path control gets **0/4** final examples; GRAFT gets **4/4**. However, a *matched-information classical exhaustive selector* also gets **4/4**. **No algorithmic superiority is claimed**. The achievement is source-native generation and externally reviewed cross-owner transfer of a **new, working executable operator**, under a finite JSON-path grammar.

The source-owner-generated module has no network, shell, storage, or production permission. CANNON emits `cannon.graft-generated-operator-review.v0` as an **unsigned, held** proposal. Neither GRAFT's generation nor CANNON's approval is automatic admission into MOTIF.
